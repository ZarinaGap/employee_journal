# 📋 Журнал учёта педагогов ДЮЦ г. Белоярский

## Описание
Приложение для учёта педагогических работников Дворца детского (юношеского) творчества г. Белоярский.

## Функционал
- ✅ Просмотр списка всех педагогов (37 человек)
- ✅ Добавление новых педагогов
- ✅ Редактирование данных педагога
- ✅ Удаление педагогов
- ✅ Загрузка фото педагога
- ✅ Поиск по ФИО
- ✅ Фильтр по отделам
- ✅ Фильтр по категории (Высшая/Первая/Без категории)
- ✅ Сортировка по алфавиту (А→Я / Я→А)
- ✅ Просмотр расписания занятий в модальном окне
- ✅ Тёмная/светлая тема
- ✅ Анимации при добавлении/удалении
- ✅ Экспорт в CSV
- ✅ Сохранение данных в localStorage

## Установка и запуск

### Требования
- XAMPP (или любой другой локальный сервер с PHP)

### Шаги для запуска
1. Установите XAMPP
2. Скопируйте папку `Employee Logbook & Schedule` в `C:\xampp\htdocs\`
3. Запустите XAMPP → включите Apache
