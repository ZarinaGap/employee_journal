## ✨ Функционал

- Авторизация пользователей (admin / 123)
- Просмотр списка педагогов (33 карточки с фото)
- Добавление, редактирование, удаление педагогов
- Загрузка фотографий
- Поиск по ФИО
- Фильтрация по специальности и категории
- Сортировка по алфавиту (А→Я / Я→А)
- Просмотр расписания занятий
- Добавление и удаление занятий
- Экспорт педагогов в CSV
- Экспорт расписания в CSV

## 🗄 База данных

**Название:** `dyut_db`

| Таблица | Описание |
|---------|----------|
| `teachers` | Педагоги |
| `schedule` | Расписание занятий |
| `users` | Пользователи |

Связь: `schedule.teacher_id` → `teachers.id` (каскадное удаление).


## 🚀 Установка и запуск

1. Установить XAMPP — https://www.apachefriends.org
2. Скопировать папку проекта в `C:\xampp\htdocs\`
3. Запустить **Apache** и **MySQL** в XAMPP
4. Открыть `http://localhost/phpmyadmin`
5. Создать базу данных `dyut_db` (кодировка `utf8_general_ci`)
6. Импортировать файл `dyut_db.sql`
7. Открыть в браузере: http://localhost/Employee_Logbook_and_Schedule/login.php
