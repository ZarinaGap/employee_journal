## 📌 О проекте

Информационная система для учёта педагогических работников Дворца детского (юношеского) творчества г. Белоярский. Разработана в рамках производственной практики (ПП 03.01, ПП 05.01, ПП 06.01).


## ✅ Функционал

- Авторизация (логин: admin, пароль: 123)
- Просмотр списка педагогов (33 человека)
- Добавление, редактирование, удаление педагогов
- Загрузка фото педагога
- Поиск по ФИО, фильтр по специальности и категории
- Сортировка по алфавиту (А→Я / Я→А)
- Просмотр и редактирование расписания занятий
- Экспорт в CSV
- Хранение данных в MySQL
- Система контроля версий (Git, GitHub)


## 🛠 Технологии

- **Backend:** PHP 7.4+, MySQL 8.0, PDO
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Сервер:** XAMPP (Apache + MySQL)
- **VCS:** Git, GitHub


## 🚀 Установка и запуск

### Требования
- Установленный [XAMPP](https://www.apachefriends.org/ru/index.html) (с Apache и MySQL)

### Шаги для запуска

1. Скопируй папку проекта в `C:\xampp\htdocs\Employee_Logbook_and_Schedule\`
2. Запусти XAMPP → включи **Apache** и **MySQL**
3. Открой phpMyAdmin (`http://localhost/phpmyadmin`) и импортируй файл `dyut_db.sql`
4. Перейди по ссылке:  
   **`http://localhost/Employee_Logbook_and_Schedule/login.php`**

### Данные для входа
- **Логин:** admin
- **Пароль:** 123


## 📁 Структура базы данных

- **teachers** — ФИО, должность, объединение, стаж, категория, специальность, фото
- **schedule** — привязка к педагогу, день недели, время, название занятия

## 📂 API-файлы (папка `api/`)

- `get_teachers.php` / `get_schedule.php` — получение данных
- `add_teacher.php` / `edit_teacher.php` / `delete_teacher.php` — CRUD для педагогов
- `add_schedule_item.php` / `delete_schedule_item.php` / `clear_schedule.php` — работа с расписанием
