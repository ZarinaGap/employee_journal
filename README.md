# 📋 Журнал учёта педагогов ДЮЦ г. Белоярский

## Описание
Информационная система для учёта педагогических работников Дворца детского (юношеского) творчества г. Белоярский. Разработана в рамках производственной практики (ПП 03.01, ПП 05.01, ПП 06.01).

## Функционал
- ✅ Авторизация (логин: admin, пароль: 123)
- ✅ Просмотр списка всех педагогов (33 человека)
- ✅ Добавление новых педагогов (с фото)
- ✅ Редактирование данных педагога
- ✅ Удаление педагогов
- ✅ Загрузка фото педагога
- ✅ Поиск по ФИО
- ✅ Фильтр по специальности (направлению деятельности)
- ✅ Фильтр по категории (Высшая/Первая/Без категории)
- ✅ Сортировка по алфавиту (А→Я / Я→А)
- ✅ Просмотр расписания занятий в модальном окне
- ✅ Редактирование расписания занятий (добавление/удаление)
- ✅ Режим редактирования (включение/отключение)
- ✅ Анимации при добавлении/удалении
- ✅ Экспорт педагогов в CSV
- ✅ Экспорт расписания в CSV
- ✅ Хранение данных в MySQL
- ✅ Восстановление и техническое сопровождение данных

## Технологии
- **Backend:** PHP 7.4+, MySQL 8.0, PDO (подготовленные запросы)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Сервер:** XAMPP (Apache + MySQL)
- **Система контроля версий:** Git, GitHub

## Структура базы данных

### Таблица `teachers`
Хранит информацию о педагогах: ФИО, должность, объединение, стаж, категория, специальность, фото.

### Таблица `schedule`
Хранит расписание занятий: привязка к педагогу, день недели, время, название занятия.

## Установка и запуск

### Требования
- XAMPP (с Apache и MySQL)
- Git (опционально, для клонирования репозитория)

### Шаги для запуска
1. Установите XAMPP
2. Скопируйте папку проекта в `C:\xampp\htdocs\Employee_Logbook_and_Schedule\`
3. Запустите XAMPP → включите **Apache** и **MySQL**
4. Откройте phpMyAdmin и импортируйте файл `dyut_db.sql` (создаст базу данных и таблицы)
5. Откройте браузер и перейдите по адресу:

## API-файлы (папка `api/`)
- `get_teachers.php` — получение списка педагогов
- `get_schedule.php` — получение расписания по педагогу
- `add_teacher.php` — добавление педагога
- `edit_teacher.php` — редактирование педагога
- `delete_teacher.php` — удаление педагога
- `add_schedule_item.php` — добавление занятия в расписание
- `delete_schedule_item.php` — удаление занятия из расписания
- `clear_schedule.php` — очистка расписания педагога
